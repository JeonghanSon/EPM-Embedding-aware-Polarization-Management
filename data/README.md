# Datasets

All datasets used in this work are publicly available from the
:contentReference[oaicite:0]{index=0} (SNAP):

https://snap.stanford.edu/data/index.html

We use the following signed network datasets:

- soc-sign-bitcoin-alpha
- soc-sign-bitcoin-otc
- wiki-Elec
- wiki-RfA
- soc-sign-Slashdot090221
- soc-sign-epinions

## Download

Each dataset can be downloaded from its corresponding SNAP page.
Please download the raw edge list files and place them under `data/raw/`.

Example:
data/raw/
├── soc-sign-bitcoin-alpha.txt
├── soc-sign-bitcoin-otc.txt
├── wiki-Elec.txt
├── wiki-RfA.txt
├── soc-sign-Slashdot090221.txt
└── soc-sign-epinions.txt
